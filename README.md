## System

The system is a patient-centric healthcare consent management system. It supports time-bounded consent, revocation, record-access requests, expiry notifications, audit-trail viewing, and protection of patient health data.

## Actors

- Patient
- Clinic Doctor
- Clinic Administrator

## Key use cases

- UC-01 Authenticate User
- UC-02 Grant Consent Access
- UC-03 Revoke Consent Access
- UC-04 View Medical Records
- UC-05 View Audit Trail
- UC-06 Request Record Access
- UC-06a Set Custom Expiry Duration
